# KB-011: Managing users, seats, and roles
Workspace admins invite users under Settings > Users > Invite. Invitations expire after 7 days and can be
resent from the same page.

Roles:
- Viewer: can view dashboards shared with them. Viewers are free and do not use a paid seat.
- Editor: can create and edit dashboards and datasets. Uses a paid seat.
- Admin: everything an editor can do, plus user, security, and billing settings. Uses a paid seat.

Adding paid seats is charged immediately with proration (see KB-005). Removing a user frees their seat
at the next renewal. Content owned by a removed user is transferred to the admin who removes them.

If an invited user never received the invitation, check that the email is spelled correctly and ask them
to check spam, or copy the invite link from the Users page and send it directly.

# KB-003: Two-factor authentication and lost devices
Brightdesk supports authenticator apps (TOTP) and security keys for two-factor authentication.

If you lost access to your authenticator device:
1. Use one of the 10 recovery codes you saved when enabling 2FA. Each code works once.
2. If you have no recovery codes, ask a workspace admin to reset 2FA for you under Settings > Users.
   You will be asked to set up 2FA again at your next sign-in.
3. If you are the only admin, Brightdesk support can reset 2FA after identity verification. This
   requires a request from the account owner's email and takes up to 2 business days. For security
   reasons support cannot shorten this process.

Workspace admins can require 2FA for all users under Settings > Security.

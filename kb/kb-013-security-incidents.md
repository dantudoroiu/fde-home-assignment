# KB-013: Suspicious activity and reporting security issues
If you see a sign-in you don't recognize, unexpected changes, or suspect a compromised account:
1. Reset the affected user's password (or revoke their SSO session in your IdP).
2. Revoke any API keys the user created (Settings > API keys).
3. Review Settings > Security > Audit log for actions taken during the suspicious period.
4. Contact support. Security reports are escalated to the Brightdesk security team immediately, 24/7.

Workspace admins can force sign-out of all sessions for a user from Settings > Users.

To report a vulnerability in Brightdesk itself, email security@brightdesk.example. Please do not include
exploit details in a regular support ticket. We acknowledge vulnerability reports within 1 business day.
